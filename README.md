# ✨ LUXE PERFUMES

A modern and responsive perfume e-commerce website built with **Next.js** and **Tailwind CSS**, featuring a clean luxury-inspired interface, dynamic product pages, advanced search, filtering, and a modern shopping experience.

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project

```bash
cd luxe-perfumes
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the development server

```bash
npm run dev
```

### 5. Open the application

Visit:

```text
http://localhost:3000
```

## 🔍 Search & Filtering

The website provides a dynamic search experience that allows users to quickly find perfumes based on available product information.

Users can:

* Search for products by name
* Search by category
* Filter products
* View matching results dynamically
* Open product details directly from search results

---

## 🛒 Shopping Experience

LUXE PERFUMES includes a modern shopping cart experience designed to keep the user inside the shopping flow.

Users can:

* Add products to the cart
* Adjust quantities
* Remove products
* View the cart from a sliding drawer
* See the number of items in the cart
* Receive confirmation when a product is added
