# 🧴 Perfume E-commerce

A modern and responsive perfume e-commerce web application built with React, designed to provide a smooth and interactive shopping experience.

## 🚀 Live Demo

[View Live Demo](https://perfume-website-design-ten.vercel.app/)

## ✨ Features

* Responsive e-commerce interface
* Modern and elegant perfume-themed UI
* Product browsing and collections
* Product search
* Product filtering
* Product categories
* Product cards
* Add products to the shopping cart
* Shopping cart management
* Product details
* Responsive design for desktop, tablet, and mobile devices
* Reusable React components
* API integration

## 🛠️ Technologies

* React
* JavaScript
* HTML5
* CSS3
* Tailwind CSS
* REST API
* Git & GitHub
* Vite

## 📱 Responsive Design

The application is fully responsive and optimized for different screen sizes, providing a consistent shopping experience across desktop, tablet, and mobile devices.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/MahmoudElkhawas/perfume-website-design.git
```

Navigate to the project directory:

```bash
cd perfume-website-design
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

## 🌐 Deployment

The application is deployed using Vercel.
